# SHP Source Sets

This directory contains non-normative source-set infrastructure for the
Structured Hardening Project.

A source-set manifest identifies a reproducible collection of SHP artefacts
for a defined working purpose.

Source-set manifests:

- do not confer normative authority;
- do not establish platform support;
- do not establish certification eligibility;
- do not modify specification status;
- do not override governed SHP metadata;
- do not supersede any SHP specification or governance record; and
- must not be treated as an independent source of certification rules.

Authority, status, platform support, certification semantics and other
governed SHP facts remain determined by their applicable authoritative
SHP sources.

A source set is a selection and integrity mechanism only.
